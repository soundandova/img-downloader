fix(ci): dist 目录改用 ASCII 名，避免非 ASCII 路径跨工具出错

可加载产物原本放在 dist/一键看图下载/。中文路径有三个实际问题：

- git 默认 core.quotepath=true，会把它转义成 dist/\344\270\200\351\224\256...，
  看 git status / ls-files / CI 日志都很费劲
- 不同平台的 tar/unzip 对非 ASCII 路径的处理不一致（本机 tar-mingw 就把
  UTF-8 字节按 GBK 解释，解出来的目录名是乱码，工具随即报"background.js 缺失"）
- 这是"别人 clone 后要拿去加载"的路径，必须最稳

改为 dist/extension/，并同步更新 README（中英）、extension/README、CONTRIBUTING。

顺带说明：CI 日志显示 dist 一致性那一步其实是过的（失败的是解析器单测），
在 Linux runner 上 UTF-8 路径处理正常。这次改名是为了消除跨平台的不确定性，
不是为了修一个必然发生的错误。
